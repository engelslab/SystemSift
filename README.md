# SystemSift
A simple, read-only Windows diagnostic tool focused on understandable system health information.

# What is SystemSift?

SystemSift is a simple, read-only Windows diagnostic tool designed to make
basic system health information easier to understand.

## SystemSift Basic

SystemSift currently checks:

- CPU
- Memory
- Storage
- Network
- Windows
- Security
- Windows Update

Instead of only displaying technical values, SystemSift tries to answer:

- What was found?
- Why does it matter?
- Is any action required?

## Read-only by design

SystemSift does not:

- delete files
- modify Windows settings
- change registry entries
- automatically "optimize" your PC

## Current version

**SystemSift Basic 0.1.0**

- Windows x64
- Portable
- No installation required
- No separate .NET runtime required
- English user interface

! SystemSift is currently in early development. !

## Security software

SystemSift reads security information reported by Windows Security Center
and can recognize registered third-party antivirus products.

## Disclaimer

SystemSift provides diagnostic information only and does not make changes
to your PC.
